Monthly Expense Tracker

A beginner-friendly Python desktop application for recording and managing monthly expenses.

Features

- Add expenses with a name, amount, and category.
- View expenses in a transaction table.
- Delete selected expenses.
- Clear all recorded expenses.
- View total spending and remaining monthly budget.
- Set and update a monthly budget.
- Save expenses in a JSON file so they remain available after restarting the application.
- Simple graphical user interface built with Tkinter.

Technologies Used

- Python
- Tkinter
- JSON
- Git and GitHub

Requirements

- Python 3 installed on your computer.
- Tkinter support in your Python installation.

How to Run

1. Download or clone this repository.

2. Open a terminal in the "monthly-expense-tracker" folder.

3. Run:
   
   python expense_tracker.py

4. The application window will open.

Data Storage

Expenses are stored locally in "expenses.json". The application creates or updates this file when expenses are saved.
