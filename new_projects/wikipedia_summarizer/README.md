# Wikipedia Summarizer (Python)

A beginner-friendly Python project that fetches a short summary of a Wikipedia article based on user input.

## Features
- Fetches summaries from Wikipedia
- Handles ambiguous or missing topics
- Simple command-line interface

## Requirements
- Python 3.x
- wikipedia library

## Installation
```bash
pip install wikipedia
```

## How to Run
```bash
python main.py
```

Type a topic when asked, for example `Python (programming language)`, and a three-sentence summary is printed.
